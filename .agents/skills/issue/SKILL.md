---
name: "Write a Github Issue"
description: "Use this when there is a bug that does not fit your current scope."
compatibility: "Requires gh cli, and a repository on github."
---

The user thinks that there is a problem with this codebase. 
First, use the `gh` tool to see if a issue already exists.
Run the code to see if it is warranted, if so please use the `gh` cli tool to write it to the issue tracker.
It must contain a meaningful title and body. Use context on why it might be happening.
DO NOT try to fix it.
